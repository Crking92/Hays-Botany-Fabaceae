# Fabaceae public photo-intake safeguards

This folder is reserved for images with image-specific legal reuse evidence, exact source and creator attribution, and a plausible Fabaceae taxon check. Unverified source originals must not be stored on a public branch. A Fabaceae 003 manifest in `photo-intake/remote-photo-manifests/` identifies candidate photo hashes for independent source checks. This README is not approval evidence.
